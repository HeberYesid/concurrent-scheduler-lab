# Guía para agentes

Laboratorio Java/Spring de scheduler con aging, benchmarks y frontend opcional.

Lee `README.md`, `docs/adr/`, `analisis_scheduler_concurrente.md` y `frontend/README.md`. Conserva las invariantes y documenta cualquier cambio de algoritmo o calibración.

```powershell
mvn test
mvn package
```

Para el frontend usa sus comandos en `frontend/package.json`. No presentes la fórmula de `agingInterval` como validada si el ejemplo y la desigualdad siguen en conflicto.
